# Google Drive 업로더 및 폴더 탐색기

이 프로젝트는 브라우저 상에서 동작하는 **Google Drive 업로더 및 폴더 탐색기** 웹 애플리케이션입니다. Google Identity Services(GIS)와 Google Drive REST API v3를 활용하여 로컬 파일을 손쉽게 구글 드라이브의 원하는 경로에 다중 업로드할 수 있으며, 기존 폴더 구조를 탐색하고 관리(다운로드 및 휴지통 이동)할 수 있는 기능을 제공합니다.

어두운 우주 테마(Dark Mode)와 유리 효과(Glassmorphism)를 반영한 미려한 디자인이 적용되어 있습니다.

---

## 🚀 빠른 시작

### 1. 로컬 개발 서버 시작하기
프로젝트 폴더 내에서 파이썬을 이용해 간단한 정적 파일 서버를 시작합니다.
```bash
python3 -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`에 접속합니다.

## ⚙️ Google Cloud API 연동 설정 방법

구글 드라이브 연동 기능을 정상적으로 사용하려면 API 키와 Client ID가 필요합니다.

1. **Google Cloud Console 접속**
   [Google Cloud Console](https://console.cloud.google.com/)에 구글 계정으로 로그인합니다.

2. **프로젝트 생성**
   새 프로젝트를 하나 생성하거나, 기존에 보유 중인 프로젝트를 선택합니다.

3. **Google Drive API 활성화**
   - 상단 검색창 혹은 왼쪽 메뉴에서 **API 및 서비스 > 라이브러리**로 들어갑니다.
   - **Google Drive API**를 검색하고 **사용(Enable)** 버튼을 클릭하여 활성화합니다.

4. **OAuth 동의 화면 설정 (처음 수행할 경우 필요)**
   - **API 및 서비스 > OAuth 동의 화면**으로 들어갑니다.
   - 사용자 유형을 **외부(External)**로 선택한 뒤 기본적인 앱 정보(앱 이름, 지원 이메일 등)를 채워 넣습니다.
   - **범위(Scopes)** 설정 시 아래의 범위들을 추가합니다.
     - `.../auth/drive.file` (이 앱이 생성/업로드한 파일 관리 권한)
     - `.../auth/drive.metadata.readonly` (드라이브 내의 폴더 구조 및 파일 목록을 보기 위한 메타데이터 권한)
   - 테스트 사용자에 자신의 구글 계정 이메일을 등록해 둡니다.

5. **사용자 인증 정보 생성**
   - **API 및 서비스 > 사용자 인증 정보**로 이동합니다.
   - **API 키 생성**:
     - `사용자 인증 정보 만들기 > API 키`를 클릭하고 생성된 키를 복사하여 애플리케이션 설정 창의 **API Key** 항목에 입력합니다.
   - **OAuth 클라이언트 ID 생성**:
     - `사용자 인증 정보 만들기 > OAuth 클라이언트 ID`를 클릭합니다.
     - 애플리케이션 유형으로 **웹 애플리케이션**을 선택합니다.
     - **승인된 JavaScript 원본** 섹션에 `http://localhost:8000`을 추가합니다. (포트 번호가 일치해야 로그인 창이 정상 작동합니다.)
     - 생성 완료 후 표시되는 **클라이언트 ID**를 복사하여 애플리케이션 설정 창의 **OAuth 2.0 클라이언트 ID** 항목에 입력합니다.

6. **설정 저장 및 로그인**
   - 두 키 정보를 입력하고 **설정 저장**을 누릅니다. (정보는 브라우저 localstorage에 임시 저장되므로 보안상 안전합니다.)
   - 상단 우측의 **구글 로그인**을 클릭하고 권한 승인 절차를 진행합니다.

## 📂 주요 기능 사용법

- **폴더 탐색 및 대상 선택**: 우측 "업로드 대상 경로 지정" 영역에서 폴더들을 더블 클릭하거나 브레드크럼(My Drive / 폴더명 / ...)을 클릭해 업로드 대상 위치를 변경할 수 있습니다.
- **파일 올리기**: 좌측 "업로드할 파일 선택"에 있는 점선 테두리 영역에 파일을 직접 끌어다 놓거나(Drag & Drop), 클릭해 다수의 로컬 파일을 로드합니다.
- **업로드 실행**: 하단의 "구글 드라이브로 업로드 시작" 버튼을 클릭하면 실시간 프로그레스 바가 움직이며 업로드가 진행됩니다.
- **새 폴더 생성**: 상단 우측의 `새 폴더 생성` 버튼으로 지정된 위치에 직접 폴더를 즉시 생성할 수 있습니다.
- **다운로드 및 삭제**: 파일 목록 오른쪽에 표시되는 아이콘을 클릭하여 드라이브 내 파일을 다운로드하거나 휴지통으로 이동시킬 수 있습니다.
