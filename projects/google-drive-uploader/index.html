API 및 인증 설정

구글 드라이브 API를 사용하려면 Google Cloud Console에서 클라이언트 ID와 API 키를 발급받아야 합니다. 입력한 정보는 브라우저의 로컬 스토리지(LocalStorage)에만 안전하게 저장되며, 서버로 전송되지 않습니다.

💡 Google Cloud Console 설정 방법

  1. Google Cloud Console에 로그인합니다.
  2. 프로젝트를 생성하거나 선택합니다.
  3. [API 및 서비스 > 라이브러리] 메뉴에서 Google Drive API를 검색하여 '사용(Enable)' 버튼을 누릅니다.
  4. [API 및 서비스 > 사용자 인증 정보] 메뉴로 이동합니다.
  5. '사용자 인증 정보 만들기'에서 API 키를 만들고 복사하여 설정창의 API Key 칸에 입력합니다.
  6. '사용자 인증 정보 만들기'에서 OAuth 클라이언트 ID를 만듭니다. (애플리케이션 유형: 웹 애플리케이션)
  7. 승인된 JavaScript 원본(Authorized JavaScript Origins)에 현재 로컬 테스트 도메인인 http://localhost:8000을 반드시 추가합니다.
  8. 생성된 클라이언트 ID를 복사하여 설정창의 Client ID 칸에 입력하고 저장합니다.
